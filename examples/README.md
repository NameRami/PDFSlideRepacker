# Examples

Place test PDFs here if you want to experiment with PDF Slide Repacker.

For copyright and repository-size reasons, no sample lecture or presentation
PDF is bundled by default.

Suggested test structure:

```text
examples/
├── sample-handout.pdf
└── README.md
```

Then copy `pdf_slide_repacker.py` into the same folder as the PDF, or run the
script from the repository root and place your source PDFs beside it.
